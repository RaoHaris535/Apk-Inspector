# Security policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose
uploaded applications or the analysis service. Send a private report through
GitHub Security Advisories with reproduction steps and the affected version.

## Data handling

APKInspector performs static analysis only. Uploaded files are processed in a
temporary directory and removed after the request completes. Users should only
submit applications they are legally permitted to inspect.

## Supported versions

Security fixes are applied to the latest release on the `main` branch.
